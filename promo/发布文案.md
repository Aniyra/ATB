## 二、简介（可直接粘贴）

```
ATB（All Tool Box）是面向 AI Agent 的全格式文件读取工具箱：
PDF、Office、图片、音视频、压缩包、数据库、电子书……一个命令，
统一成模型能直接读的文本与结构化数据。

它还内置 MCP Server，可以直接挂到 Trae / Claude Desktop / Cursor：
让 Agent 自己决定读哪个文件、怎么读，而不是等人来转格式。

✨ 本版亮点
• 17 类格式 / 250 个扩展名，扩展名 + 魔术字节双重识别
• CLI / Python API / MCP Server 三种接入
• 视频分镜：一张宫格图覆盖全片，编号 + 时间码 + 音频包络 + 字幕对齐
• 局部放大：按时间点取全分辨率画面，看清分镜里的小字
• 可选额度查询、历史对话压缩；电脑操作（实验性，仅 Windows）
• v1.3.0：分镜转为正式功能，332 秒视频约 7.3s
• 81 项单元测试，Windows 单文件 exe，免安装

⏱ 时间轴
00:00 开场
00:05 一个命令，读遍所有格式
00:13 17 类格式 · 250 个扩展名
00:21 视频分镜：一张图看全片
00:31 接入 Agent：MCP Server
00:39 性能：3 倍提速
00:46 项目地址

💻 快速开始
atb read "报告.pdf" --md
atb storyboard "视频.mp4"
atb mcp

MCP 配置：
{
  "mcpServers": {
    "atb": { "command": "ATB.exe", "args": ["mcp"] }
  }
}

🔗 GitHub：https://github.com/Aniyra/ATB
📦 v1.2.0：https://github.com/Aniyra/ATB/releases/tag/v1.2.0

🧪 技术栈
Python 3.14 / PyMuPDF / PyAV / Pillow / openpyxl / python-docx /
python-pptx / py7zr / pyarrow

🧩 说明
分镜算法思路参考 SAOS-3624/dsh-video-storyboard（Apache-2.0），
本项目为基于 PyAV + Pillow 的独立 Python 实现，未复制其源码。
画面素材来自我自己的 Remotion 项目；配乐由脚本现场合成，无第三方版权素材。

#AI# #MCP# #开源# #Python# #效率工具# #程序员#
```
